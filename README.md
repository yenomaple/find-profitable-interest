# Find Profitable Interest

一个通过证据式访谈，帮助用户找到“值得验证的盈利兴趣”的 Agent Skill。

它不做性格测试，也不直接推荐热门副业。它会从用户真实做过的事情中，区分价值目标、主题兴趣、生产行为、恢复性兴趣和工作方式，再把最有证据的生产行为连接到具体用户、问题、可售结果和验证实验。

## 它解决什么问题

- 我不知道自己真正喜欢什么。
- 我想把兴趣变成工作或副业。
- 我对很多东西都感兴趣，但不知道哪个值得长期做。
- 我想赚钱，但不想靠持续消耗自己的方式赚钱。
- 我需要的不是方向清单，而是一项可以验证的下一步行动。

## 安装

```bash
npx -y skills add yenomaple/find-profitable-interest -g --all
```

安装后可以直接说：

```text
使用 $find-profitable-interest，帮我找到值得验证的盈利兴趣。
```

## 核心方法

```text
盈利兴趣假设
= 愿意重复的生产行为
× 具体用户
× 具体问题
× 可售结果
× 相容的工作方式
```

Skill 会一次只问一个问题，区分事实、推断和未知，最终输出：

1. 一句话结论；
2. 兴趣结构；
3. 最多三个候选生产循环；
4. 首选假设、反例和置信度；
5. 一个与当前证据阶段匹配的 7 天验证动作。

## 来源与修改说明

本 Skill 基于 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill) 的商业诊断方法，以及 dontbesilent 关于“把兴趣变成工作”“生产型兴趣”的公开内容二次创作，**不是官方 dbskill**。

在原始方法的基础上，本项目新增并明确化了：

- 证据式单问题访谈；
- 价值目标、主题兴趣、生产行为、恢复性兴趣和工作方式的分层；
- `事实 / 推断 / 未知` 标记；
- 按证据成熟度选择验证动作；
- 固定报告结构与低推理预算模型的行为约束。

感谢 dontbesilent 对核心问题的启发：兴趣本身不能直接变成钱，能够进入交易的是围绕兴趣形成的具体产出。
