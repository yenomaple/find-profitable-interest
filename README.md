# Find Profitable Interest

一个先帮用户确认“自己究竟对什么感兴趣”，再由用户决定是否继续讨论赚钱的 Agent Skill。

它不做性格测试，也不直接推荐热门副业。它会从用户真实做过的事情中，区分价值目标、主题兴趣、喜欢的生产行为、奖励时刻、恢复性兴趣和工作方式，先形成一份可纠正的兴趣画像。只有用户明确确认画像并愿意继续，才连接具体用户、问题、可售结果和验证动作。

## 它解决什么问题

- 我不知道自己真正喜欢什么。
- 我喜欢很多东西，但分不清是好奇、消费兴趣，还是愿意长期做。
- 我想先理解自己的兴趣，再决定要不要把它变成工作或副业。
- 我想赚钱，但不想靠持续消耗自己的方式赚钱。
- 我不需要一份热门方向清单，而需要基于自己经历的判断。

## 安装

```bash
npx -y skills add yenomaple/find-profitable-interest -g --all
```

安装后可以直接说：

```text
使用 $find-profitable-interest，先帮我弄清楚自己真正感兴趣的是什么；在我确认前，不要推荐赚钱方向。
```

## 工作顺序

```text
真实经历
→ 兴趣画像草案
→ 用户纠正并明确确认
→ 可选：连接赚钱方式
→ 用户选择候选
→ 可选：设计一个验证动作
```

第一阶段会区分：

- 想得到什么：自由、安全感、收入、影响力等价值与目标；
- 关注什么：AI、商业、故事、运动等主题兴趣；
- 喜欢做什么：发现、研究、判断、制作、表达、销售、优化等生产行为；
- 哪一刻有奖励：发现机会、做出成品、成交、增长、被认可等；
- 怎样工作更舒服：独立或协作、同步或异步、高接触或低接触；
- 什么只负责恢复精力：阅读、游戏、独处、旅行等恢复性兴趣；
- 新鲜感过去后，什么仍愿意长期优化。

用户确认兴趣画像后，第二阶段才使用：

```text
盈利兴趣假设
= 已确认的生产行为
× 具体用户
× 具体问题
× 可售结果
× 相容的工作方式
```

Skill 设置了两道确认门槛：确认兴趣画像前不推荐职业、副业、产品或行动；选择盈利候选前不设计验证动作。用户可以停在任何阶段。

## 来源与修改说明

本 Skill 基于 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill) 的商业诊断方法，以及 dontbesilent 关于“把兴趣变成工作”“生产型兴趣”的公开内容进行二次创作，**不是官方 dbskill，也不依赖 dbskill 路由**。

在原始理念的基础上，本项目新增并明确化了：

- “确认兴趣 → 连接赚钱 → 验证行动”的严格阶段顺序；
- 兴趣画像与盈利假设之间的用户确认门槛；
- 证据式单问题访谈；
- 价值目标、主题兴趣、生产行为、奖励时刻、恢复性兴趣和工作方式的分层；
- `事实 / 推断 / 未知` 标记；
- 固定输出结构与低推理预算模型的行为约束。

感谢 dontbesilent 对核心问题的启发：兴趣本身不能直接变成钱，能够进入交易的是围绕兴趣形成的具体产出。
